# AI vs ML vs DL vs Data Science

## The Big-Picture Relationship Between These Fields

This topic introduces the relationship between Artificial Intelligence (AI), Machine Learning (ML), Deep Learning (DL), and Data Science.

## 1. Artificial Intelligence (AI)

Artificial Intelligence focuses on building systems that perform tasks associated with intelligent behavior, often with limited or no direct human intervention.

**Examples:**
- Netflix recommendation systems
- Self-driving cars
- Amazon recommendation systems

**Key idea:** AI is the broader field concerned with intelligent machine behavior.

## 2. Machine Learning (ML)

Machine Learning is a subset of AI. It uses algorithms that learn patterns from data to make predictions, classifications, recommendations, or other decisions.

**Common applications:**
- Learning patterns from data
- Making predictions
- Classification
- Forecasting
- Supporting data-driven decisions

**Key idea:** ML is one approach to building AI systems by learning from data.

## 3. Deep Learning (DL)

Deep Learning is a specialized subset of Machine Learning that uses neural networks with multiple layers.

These multilayer neural networks can learn complex patterns from data and are used in image recognition, speech recognition, and language processing.

**Key idea:** DL is an ML approach based on multilayer neural networks.

### The hierarchy

```text
Artificial Intelligence (AI)
└── Machine Learning (ML)
    └── Deep Learning (DL)
```

Not every AI system uses ML, and not every ML system uses Deep Learning.

## 4. Data Science (DS)

Data Science is an interdisciplinary field focused on extracting insights and value from data.

It combines:
- Exploratory Data Analysis (EDA)
- Feature engineering
- Statistics and probability
- Mathematics
- Data visualization
- Machine Learning
- Deep Learning
- Domain knowledge

Data Science is not simply a subset of AI. It overlaps with AI, ML, and DL while also including work that does not require these techniques, such as descriptive analysis and statistical reporting.

**Key idea:** Data Science is a data-focused discipline that uses a range of methods and tools, including ML when appropriate.

## 5. Quick Comparison

| Field | Think of it as | Typical focus |
|---|---|---|
| Artificial Intelligence | The broader field of intelligent systems | Performing intelligent tasks |
| Machine Learning | One approach to AI | Learning patterns from data |
| Deep Learning | A specialized ML approach | Multilayer neural networks |
| Data Science | An interdisciplinary data-focused field | Understanding data and deriving insights |

## 6. The Mental Model

- **AI:** The broader field of intelligent systems.
- **ML:** One route toward AI, using patterns learned from data.
- **DL:** A specialized route within ML, using multilayer neural networks.
- **Data Science:** A broader interdisciplinary practice that overlaps with AI, ML, and DL.

Remember: AI, ML, and DL have a nested relationship. Data Science intersects with them rather than forming another level in that hierarchy.

## Key Takeaway

AI is the broader field; ML is one approach within AI; DL is a specialized approach within ML; and Data Science is an interdisciplinary field that may use any of these techniques.
