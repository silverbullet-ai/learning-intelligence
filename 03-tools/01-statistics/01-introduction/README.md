# Statistics - Introduction

## Overview

Statistics is the branch of mathematics concerned with collecting, organizing, analyzing, interpreting, and presenting data. It provides the foundation for understanding data, identifying patterns, and making informed decisions based on evidence rather than assumptions.

Today, statistics plays a fundamental role in fields such as Data Science, Machine Learning, Artificial Intelligence, Business Analytics, Healthcare, Finance, and Scientific Research.

---

# What is Statistics?

Statistics is the science of working with data.

It involves five major stages:

1. Collection of Data
2. Organization of Data
3. Analysis of Data
4. Interpretation of Data
5. Presentation of Data

The primary objective of statistics is to transform raw data into meaningful information that supports decision-making.

---

# Why Do We Need Statistics?

Raw data alone often provides little insight. Statistics helps convert large collections of numbers into meaningful information.

Statistics enables us to:

- Summarize large datasets
- Identify trends and patterns
- Compare different groups
- Measure variability
- Make predictions
- Support data-driven decisions

Without statistical analysis, data remains difficult to interpret and use effectively.

---

# Statistical Workflow

Every statistical problem generally follows the same workflow.

```
Data Collection

        ↓

Data Organization

        ↓

Data Analysis

        ↓

Data Interpretation

        ↓

Data Visualization

        ↓

Decision Making
```

Each stage contributes to transforming raw observations into actionable insights.

---

## Probability Density Function (PDF)

A Probability Density Function (PDF) represents the relative likelihood of different values occurring within a continuous dataset.

It provides a smooth curve that describes the distribution of data.

---

## Cumulative Distribution Function (CDF)

A Cumulative Distribution Function (CDF) shows the cumulative probability that a variable takes a value less than or equal to a specified point.

CDFs are commonly used to understand probabilities and percentiles within a dataset.

# Real-World Example

## ATM Installation Decision

Suppose a bank wants to install a new ATM.

Before investing money, the bank needs answers to questions such as:

- How frequently is the existing ATM used?
- What is the average monthly transaction volume?
- Is there sufficient customer demand at the proposed location?
- Will the new ATM generate enough revenue?

To answer these questions, historical transaction data is collected and analyzed.

The bank evaluates:

- Average daily transactions
- Peak usage periods
- Customer density
- Operational costs
- Expected profitability

The final decision is based on statistical evidence rather than assumptions.

---

## Vaccine Testing

Statistics is equally important in healthcare.

Before a vaccine is approved:

1. Volunteers are selected.
2. Clinical trials are conducted.
3. Data is collected.
4. Statistical analysis is performed.
5. Safety and effectiveness are evaluated.

Only after sufficient statistical evidence is obtained can the vaccine be approved for public use.
