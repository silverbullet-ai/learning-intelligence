# Learning Intelligence

> An evolving exploration of intelligence, combining mathematics, machine learning, and systems thinking.

## About

**Learning Intelligence** is my personal learning repository dedicated to building a strong foundation in programming, mathematics, data science, and artificial intelligence.

It documents my learning journey through structured notes, practical implementations, experiments, and projects — connecting theoretical concepts with hands-on applications.

Rather than simply collecting code, this repository aims to develop a deeper understanding of how intelligent systems work, how they learn from data, and how mathematical principles shape their behavior.

## Learning Philosophy

- **Understand before implementing:** Build conceptual clarity before relying on libraries.
- **Mathematics behind intelligence:** Understand the principles that drive algorithms and models.
- **Learn by building:** Reinforce concepts through exercises, experiments, and projects.
- **Connect theory with practice:** Translate mathematical ideas into working implementations.
- **Think in systems:** Understand how individual components interact within larger intelligent systems.
- **Document the journey:** Maintain structured notes and reproducible examples as learning progresses.
