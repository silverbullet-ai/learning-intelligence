## About

**Learning Intelligence** is my personal learning repository focused on developing a strong foundation in programming, mathematics, data science, and artificial intelligence.

It documents my learning journey through structured notes, practical implementations, experiments, and projects, connecting theoretical knowledge with real-world applications.

The central idea is to go beyond using libraries and frameworks — understanding the mathematical principles, algorithms, and computational processes that make intelligent systems work.

## Learning Philosophy

- **Understand Before Implementing:** Develop conceptual clarity before relying on libraries and frameworks.
- **Mathematics Behind Intelligence:** Understand the mathematical principles that drive algorithms and machine learning models.
- **Learn by Building:** Reinforce theoretical knowledge through exercises, experiments, and practical projects.
- **Connect Theory with Practice:** Translate mathematical and computational concepts into working implementations.
- **Think in Systems:** Understand how individual components interact within larger intelligent systems.
- **Document the Journey:** Maintain structured notes, reproducible examples, and technical documentation as learning progresses.
