# Variables in Statistics

## Overview

Before analyzing data, it is important to understand what a **variable** is, because statistics deals with different types of variables.

A variable is any characteristic or property that can take different values across different observations.

Examples include:

- Age
- Height
- Gender
- Weight
- Color
- Salary

Understanding the type of variable helps determine which statistical methods and visualizations are appropriate.

---

# What is a Variable?

A **variable** is a property or characteristic that can take different values.

Examples:

```text
Age = 25

Age = 30
```

Here:

- **Age** is the variable.
- **25** and **30** are values of the variable.

A single observation has only one value for a variable, but different observations may have different values.

---

# What is NOT a Variable?

```text
[12, 20, 25, 30]
```

This is **not** a variable.

It is a collection of values belonging to a variable (for example, Age).

---

# Types of Variables

Variables are broadly divided into two categories.

```text
Variables

│

├── Quantitative (Numerical)

│      ├── Discrete

│      └── Continuous

│

└── Qualitative (Categorical)
```

---

# 1. Quantitative Variables

A Quantitative Variable stores numerical values.

These values can be measured or counted.

Examples:

- Age
- Height
- Weight
- Salary
- Number of Students

Quantitative variables are further divided into:

- Discrete Variables
- Continuous Variables

---

# 1.1 Discrete Variables

A Discrete Variable can take only whole-number (countable) values.

Fractions or decimal values are not possible.

## Examples

### Number of Children

```text
✔ 2 Children

✔ 3 Children

✔ 5 Children

✘ 2.5 Children
```

---

### Number of Houses

```text
✔ 1 House

✔ 3 Houses

✘ 3.7 Houses
```

---

### Number of Bank Accounts

```text
✔ 2 Accounts

✔ 5 Accounts

✘ 2.5 Accounts
```

---

### Number of Students

```text
✔ 40 Students

✔ 55 Students

✘ 40.8 Students
```

---

### Number of Employees

```text
✔ 150 Employees

✘ 150.4 Employees
```

---

## Characteristics

- Countable
- Whole numbers only
- No decimal values

---

# 1.2 Continuous Variables

A Continuous Variable can take any value within a range.

These values may contain decimal points.

Examples include:

- Height
- Weight
- Age
- Temperature
- Distance

---

## Height

```text
175 cm

175.5 cm

175.75 cm
```

---

## Weight

```text
70 kg

70.3 kg

70.85 kg
```

---

## Age

```text
20 Years

20.5 Years

20.75 Years
```

Although age is commonly written as whole numbers, it actually changes continuously over time.

---

## Temperature

```text
25°C

25.4°C

25.82°C
```

---

## Distance

```text
10 km

10.75 km
```

---

## Characteristics

- Measured rather than counted
- Decimal values allowed
- Infinite possible values within a range

---

# Difference Between Discrete and Continuous Variables

| Discrete Variable | Continuous Variable |
|-------------------|---------------------|
| Countable | Measurable |
| Whole numbers only | Decimal values allowed |
| Finite values | Infinite possible values |
| Example: Students | Example: Height |

---

# 2. Qualitative (Categorical) Variables

A Qualitative Variable (Categorical Variable) represents labels or categories rather than numerical measurements.

These variables describe qualities or characteristics.

---

## Examples

### Gender

```text
Male

Female
```

---

### Color

```text
Red

Green

Blue

Black
```

---

### Blood Group

```text
A

B

AB

O
```

---

### State

```text
Karnataka

Bihar

Maharashtra
```

---

### Department

```text
HR

Finance

Marketing

IT
```

---

### Marital Status

```text
Single

Married

Divorced
```

---

## Characteristics

- Represent categories
- Used for grouping or classification
- Mean, Variance, and Standard Deviation are generally not calculated directly
